# REQ-2026.2-T02-UniCash
Repositório de projeto da disciplina de REQ-T2 - 2026.2.

## Manutenção da documentação

- Ao alterar uma página em `unicash/docs/`, acrescente uma linha à seção **Histórico de versões** no fim dela, com a próxima versão, a data, a descrição da mudança e o autor.
- Decisões que mudam escopo, requisitos, processo ou arquitetura entram no [Registro de decisões](unicash/docs/decisoes.md) com o próximo identificador (D20, D21...). Os requisitos afetados citam a decisão na coluna **Origem**.
- Ao incluir ou alterar um requisito, preencha as colunas **Origem** (ata ou decisão) e **Situação** (Proposto, Vigente, Entregue ou Retirado). Requisitos propostos também entram em **Pontos para validação**.
