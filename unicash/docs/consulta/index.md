# Catálogo de requisitos

Consulte em um só lugar todas as características de produto (CP), casos de uso (UC), requisitos funcionais (RF), requisitos não funcionais (RNF) e regras de negócio (RN). Clique no código para abrir a página do item, com suas relações e as páginas em que ele é mencionado. O menu lateral também lista cada item, agrupado por característica, classificação ou tipo.

!!! tip "Atalhos"
    - Em qualquer página do site, os códigos (por exemplo RF07, RNF35 ou RN03) viram links: passe o mouse para ver o nome e clique para abrir.
    - O filtro fica na URL. Copie o endereço para compartilhar uma consulta, por exemplo `#q=sincroniz&tipo=RNF`.
    - Pressione ++slash++ para focar no campo de busca do catálogo.
