# Registros de Engenharia de Requisitos

Esta página reúne os registros das reuniões e das versões dos requisitos que servem como evidência das atividades de Engenharia de Requisitos descritas na seção 5. Os registros estão em ordem cronológica, e os identificadores R01 a R08 são usados na seção 5.6. As reuniões com transcrição foram gravadas no Microsoft Teams, e as transcrições são mantidas pela equipe.

Cada ata começa por um resumo, que também pode ser ouvido no player de áudio (narração gerada com voz neural a partir do texto do resumo). Use as categorias e o arquivo no menu lateral para filtrar as atas.
